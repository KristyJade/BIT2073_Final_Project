## 🍟 About the Project

**Whack Food Corner** is an interactive food delivery website that provides a simple and organized way to **browse food, place orders, manage the cart, complete checkout, and track orders**.

The website applies **Human Computer Interaction (HCI)** principles to create a clear, consistent, and user-friendly ordering experience.

---

## 🎯 Project Objective

To develop a **user-friendly and well-structured food delivery website** that combines practical ordering functions with HCI principles for a more efficient digital ordering experience.

---

## ✨ Key Features

| Feature                | Description                                   |
| :--------------------- | :-------------------------------------------- |
| 🍔 **Food Browsing**   | Browse burgers, chicken delights, and drinks  |
| 🛒 **Online Ordering** | Select food and manage cart items             |
| 🏷️ **Promo & Notes**  | Apply promo codes and add special order notes |
| 💳 **Checkout**        | Review orders and select payment methods      |
| 📦 **My Orders**       | View status, track orders, and reorder        |
| 👤 **Account**         | Manage account and personal information       |
| 💬 **Support**         | Access contact information and assistance     |

---

## 🔄 User Flow

`Home` → `Menu / Order Online` → `Cart` → `Checkout` → `My Orders`

A structured ordering journey helps users move naturally from **food discovery to post-order management**.

---

## 🎨 HCI Principles

`Usability` · `Feedback & Affordance` · `Error Prevention` · `Accessibility`

These principles help make the website **clear, consistent, accessible, and easy to navigate**.
